# AI Backtest Lab

AI-assisted quantitative research for individuals and teams.

AI Backtest Lab is an independent, bootstrapped project developed in Vietnam by
[Nguyen Thanh Dat](https://github.com/DyanNguyen22). It is not an incorporated company.

- Website: https://aibacktestlab.com
- Interactive demo (static, synthetic data): https://demo.aibacktestlab.com
- Contact: founder@aibacktestlab.com

## What works today

The research engine runs in a private development environment:

- Historical crypto backtesting with explicit fees, funding and slippage
- Performance and risk metrics: returns after costs, drawdown, equity curve, trade log
- Research validation: automated quality checks, run comparison and a recent-period check

## Planned

- Claude-powered interpretation of structured backtest results: risk explanations and testable hypotheses
- Broader out-of-sample validation
- Public early access

## How it fits together

Historical market data → backtesting engine → quantitative metrics → research validation → dashboard.
The public demo is a static site on synthetic data; it does not run backtests on a backend.
